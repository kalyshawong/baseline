### A9. HRV CV threshold — doc states the flat threshold as if it's the live one

> `Elevated HRV CV is an early marker of non-functional overreaching even when absolute values haven't dropped (Flatt & Esco 2016; CV > 10% flagged).`

Citation is implemented but **10% is now only the fallback**. `src/lib/training.ts:148` defines `FLAT_HRV_CV_THRESHOLD = 10`, and `hrvCvThreshold(baseline)` (`training.ts:198`) returns it *only when `baseline` is null*. The live path is `rollingHrvCvBaseline()` → a personal threshold, with `src/app/body/page.tsx:232` switching on an `hrvChoice === "standard"` flag. UI text at `body/page.tsx:455` already distinguishes `"(Flatt threshold 10%)"` from `"(your normal ~N%)"`.

This is the documented fix for the known mis-calibration (her HRV runs ~20ms, so a flat 10% CV fired daily). features.md still promises the broken behavior.
