### 1.5 features.md: HRV CV threshold citation is stale (CRITICAL PATH)
`features.md` L57 states the readiness tier flags "CV > 10%" (`Flatt & Esco 2016; CV > 10% flagged`). The flat 10% rule was **recalibrated on 2026-05-29** and is no longer the operative flag. `lib/training.ts` L124–140 documents the change and keeps `FLAT_HRV_CV_THRESHOLD = 10` only as a constant; the live signal is now a *personalized* baseline via `rollingHrvCvBaseline()` (L159), and the dashboard/coach use `getHrvBaselineSummary` (`training-call.ts`) and report "above your ~X% baseline" (`coach-context.ts` L309). The in-code comment explicitly notes the flat 10% cutoff "fired every single day (55/55 windows)" for this user. **Doc promises a threshold the code deliberately abandoned.**

The score engine still exists and its math is unchanged (see 3.2), but the page composition the docs describe no longer matches. `features.md` `/` section (L8–41) lists "Six metric cards: Readiness, Sleep, HRV, Stress, SpO2, Resilience" and other cards that broadly exist, but does not describe the Today-Call hero / Do / Tonight structure.

### 1.7 architecture.md lib/ inventory omits the central cycle-phase module (CRITICAL PATH)
